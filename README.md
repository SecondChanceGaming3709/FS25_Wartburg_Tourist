# FS25 Wartburg 353 Tourist

A classic **Wartburg 353 Tourist** and matching functional camper trailer for **Farming Simulator 25**.

The pack combines a drivable, customizable Wartburg with a deployable camper that includes an opening door, condition and color options, and a working sleep function.

## Included Vehicles

### Wartburg 353 Tourist

- 70 hp engine
- Top speed of approximately 105 km/h
- Manual four-speed transmission
- Seating for the driver and four passengers
- Working lights, turn signals, brake lights, and dashboard gauges
- Front and rear license plates
- Functional rear attachment for the camper
- Tension belts
- Opening tailgate
- Interactive interior controls
- Main body and seat color configurations
- New and rusted condition options
- Dirt and wear support

### Wartburg Tourist Camper

- Functional towable camper trailer
- Compatible with car, standard trailer, and low trailer hitches
- Deployable camper setup and support
- Interactive opening camper door
- Functional sleep point with sleep marker and camper camera
- Working road lights and reflectors
- Main body, fabric, and mattress color configurations
- New and rusted condition options
- Dirt and wear support

## Installation

1. Download `FS25_wartburg_tourist.zip` from the latest GitHub release.
2. Do **not** extract the ZIP.
3. Place it in your Farming Simulator 25 mods folder:

   `Documents/My Games/FarmingSimulator2025/mods`

4. Start Farming Simulator 25 and enable the mod when loading your save.

Because the camper uses a custom Lua specialization for sleeping, this mod is intended for the PC/Mac version of Farming Simulator 25.

## Multiplayer

Multiplayer is supported. Every player joining the game must have the same version of the mod installed.
